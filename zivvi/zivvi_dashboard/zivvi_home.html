Smart User Guide

Learn how to use ZIVVI like a pro 🚀

Welcome to ZIVVI 💡

  • Set your monthly budget in Settings
  • Add your first expense
  • Start tracking your money in real-time

Fill these fields carefully:

  • Item Name → What you spent on
  • Amount → Money spent
  • Category → Food, Travel, Bills, etc.
  • Payment → UPI / Card / Cash
  • Bank → Optional but useful

💡 Tip: Accurate data = better AI insights

  • Available Balance → Remaining money
  • Spent → Total expenses
  • Limit → Budget
  • Usage % → How much budget used

🔥 Color changes (Green → Red) show your financial health

  • Detects highest spending category
  • Shows spending patterns
  • Warns if overspending ⚠️

💡 AI works only when enough data is available

  • Trend chart → Last spending pattern
  • Daily average & peak spending
  • Predicted balance for month
  • Spending health (Excellent → Critical)
  • Filter by date (Today, Month, Year)
  • Filter by payment method
  • Search transactions easily
  • Log every expense daily 📅
  • Use categories properly
  • Check analytics weekly
  • Set realistic budget
